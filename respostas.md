# Respostas das atividades
## Atividade 1
**Resposta:** o index.html vai estruturar a página, bem como o conteúdo. É onde organizamos os elementos que o usuário irá visualizar(menu, títulos, texto etc).
o style.css será o resposável por por estilizar a página. Cores, fontes, alinhamentos etc. 
## Atividade 2
**Resposta:** "<!DOCTYPE html>" declara que utilizaremos o HTML5.
## Atividade 3
**Resposta:** "<title>Meu Projeto Web</title>" fará aparecer o título da página na aba do navegador.
## Atividade 4
**Resposta:** a tag "<h1>" representam o título e a tag "<p>" representam o parágrafo.
## Atividade 5
**Resposta:** Para a seção temática utilizamos a tag "<section>"
## Atividade 6
**Resposta:** utilizamos a "<nav>" juntamente com uma lista ordenada, "<ul>", para a criação da lista dos links. A tag <a> serve como uma âncora para conectar links dentro da página, bem como externos.
## Atividade 7
**Resposta:** utilizei o atributo "<id>" para identificação única. "<a href="#sobre">Sobre</a>" é a forma correta para apontar para o destino.
## Atividade 8 
**Resposta:** para identificar o caminho da imagem utiliza-se o "src" e para a descrição "alt".
## Atividade 9 
**Resposta:** <figure> serve para agrupar as imagens e a "<figurecaption>" para a legenda.
## Atividade 10 
**Resposta:** usei o atributo href para definir o endereço.
## Atividade 11 
**Resposta:** o link interno irá direcionar o usuário para alguma parte dentro da página, já o externo utilizará um elemento externo ou outra página. 
## Atividade 12
